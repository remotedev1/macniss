# Homepage imagery

Created with the built-in ImageGen tool. All photographs are architectural illustrations. The homepage uses actual CMS photos when available and identifies generated stand-ins on project cards.

The files below are stored in `public/images/home/` as WebP. The three opening frames also have `-mobile.webp` variants.
